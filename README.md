# Mulgil Kim 风格改画 Skill

将上传的照片或图片改画为 Mulgil Kim（金水路，김물길）风格的画作。适用于具有内置图片生成与编辑工具的 Codex 环境。

绘画前先确定**梦幻程度**和**笔触精细度**，两项独立控制；其余参数按需补充。输出为 AI 改画，不是艺术家本人作品。

## 安装

让 Codex 安装本仓库中的 `mulgil-kim-painter` 目录，或将该目录完整复制到 `~/.codex/skills/`。保留目录内的 `SKILL.md` 和 `agents/openai.yaml`。

如果新会话没有识别到该技能，可以要求 Codex 读取 `mulgil-kim-painter/SKILL.md` 后执行。依赖内置 `image_gen`，无需单独配置 API 密钥。

## 使用

上传图片后输入：

> 使用 $mulgil-kim-painter，把这张图片改为金水路风格。

未指定梦幻和笔触偏好时，agent 会先询问并等待回复。也可以直接指定：

> 梦幻程度明显，笔触松散，忠于原图，绿蓝自然色，其他沿用原图。

> 梦幻感强烈，但笔触细腻；适度重构，月夜氛围，轻微纸纹，保留原比例。

说“你决定”时允许 agent 自行选择并说明所用参数。

## 可选参数

| 参数 | 选择 | 未指定时 |
| --- | --- | --- |
| 梦幻程度 | 轻微 / 明显 / 强烈 | 绘画前询问 |
| 笔触精细度 | 松散 / 适中 / 细腻 | 绘画前询问 |
| 原图保留程度 | 忠于原图 / 适度重构 / 大胆改编 | 忠于原图 |
| 色彩倾向 | 原图配色 / 绿蓝自然色 / 柔和暖色 / 自定义 | 原图配色 |
| 光线与情绪 | 原图光线 / 清新日光 / 温柔黄昏 / 静谧月夜 / 自定义 | 原图光线 |
| 材质感 | 平整哑光 / 轻微纸纹 / 明显颜料纹理 | 平整哑光 |
| 画幅 | 原比例 / 方形 / 竖版 / 横版 / 指定比例 | 原比例 |

这些参数控制生成提示，并非图片工具的独立数值接口。具体效果仍需查看生成结果。
