# Mulgil Kim 风格改画 Skill

把你的照片画成带有 Mulgil Kim（金水路，김물길）风格的水粉画：柔和的绿与蓝，安静的环境，还有像波浪或布料一样流动的自然形态。

画之前会先问你两件事：想要多梦幻，笔触想要多细。可以大胆梦幻又细腻，也可以贴近原图、画得松一些。配色、光线和构图有想法也可以直接说。

需要 Codex 的内置图片生成工具。得到的是 AI 改画。

## 安装

让 Codex 安装本仓库中的 `mulgil-kim-painter` 目录，或将该目录完整复制到 `~/.codex/skills/`。保留目录内的 `SKILL.md`、`agents/` 和 `references/`。

如果 Codex 没有识别到它，让 Codex 读取 `mulgil-kim-painter/SKILL.md` 即可。无需另配 API 密钥。

## 使用

上传图片后输入：

> 使用 $mulgil-kim-painter，把这张图片改为金水路风格。

也可以把想法一起说清楚：

> 梦幻一点，笔触松一些。保留原来的构图，加一点绿，其他照原图来。

> 想要很梦幻的月夜，笔触细腻，带一点纸纹。背景可以改，人物和画幅别动。

没想好就说“你决定”。已经说过的偏好不会再问。

想省事，可以选“自然细腻”“梦幻松散”或“梦幻细腻”。搭配见 [快捷预设](mulgil-kim-painter/SKILL.md#快捷预设)，每一项都可以再改。

喜欢某一版后，可以说“就用这张，把笔触放松一点”。接下来会在这张图上修改，另存一版，原来的图也会保留。

## 有喜欢的参考图吗

可以一起上传，说明哪张要改画、哪张用来参考。参考图主要看颜色、笔触和形态，照片里的主体与场景仍以你的要求为准。没有参考图也能画。

开画前会简单说一下准备怎么改，比如“人物和背包保留，远处山坡像绿色布料一样卷起来”。说完就画，不用再确认一次。更多例子见 [风格指导](mulgil-kim-painter/references/style-guide.md)。

## 可以调整什么

| 参数 | 选择 | 未指定时 |
| --- | --- | --- |
| 梦幻程度 | 轻微 / 明显 / 强烈 | 绘画前询问 |
| 笔触精细度 | 松散 / 适中 / 细腻 | 绘画前询问 |
| 原图保留程度 | 忠于原图 / 适度重构 / 大胆改编 | 忠于原图 |
| 色彩倾向 | 原图配色 / 绿蓝自然色 / 柔和暖色 / 自定义 | 原图配色 |
| 光线与情绪 | 原图光线 / 清新日光 / 温柔黄昏 / 静谧月夜 / 自定义 | 原图光线 |
| 材质感 | 平整哑光 / 轻微纸纹 / 明显颜料纹理 | 平整哑光 |
| 画幅 | 原比例 / 方形 / 竖版 / 横版 / 指定比例 | 原比例 |

不用逐项填写，自然说出想要的画面就好。这些选项用来描述方向，效果要看实际出图。
